# Privacy Policy

**Personal Oura Data Pipeline** is a single-user, personal project by Almaz Sadykov.

- This application accesses **only the developer's own Oura account data**, with the account owner's explicit consent (they are the same person).
- Data is stored **locally on the developer's own machine** in a local database.
- No data is shared with, sold to, or made accessible to any third party.
- No raw health data is published. Any public analysis (charts, notebooks, README figures) contains **aggregated, derived statistics only**.
- The application is not distributed and has no users other than the developer.
- Data can be deleted at any time by dropping the local database and revoking the application's access at cloud.ouraring.com.
